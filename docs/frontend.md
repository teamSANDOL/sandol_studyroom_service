# 테스트용 페이지

FastAPI는 `/`에서 열람실과 스터디룸의 가상 현황을 제공한다. 페이지는 학교에 요청하지 않는다. 좌석 상태와 예약 기록은 예시이며 실제 이용 가능 여부를 나타내지 않는다. 가상 현재 시각은 한국 기준 오늘 14:10으로 고정한다.

## 파일 역할

- `app/routers/web.py`는 HTML 파일을 응답한다.
- `app/template/index.html`은 페이지 구조를 정의한다.
- `app/static/css/style.css`는 배치도, 시간표와 화면 배치를 정의한다.
- `app/static/js/app.js`는 페이지를 초기화하고 실제 `/studyroom/health`를 요청한다.
- `app/static/js/mock-data.mjs`는 가상 좌석 상태와 예약 기록을 생성한다.
- `app/static/js/readingroom.mjs`는 열람실 선택, 좌석 배치도, 검색과 상세 정보를 연결한다.
- `app/static/js/studyroom.mjs`는 현재 방 상태와 날짜별 시간표를 표시한다.
- `app/static/js/history.mjs`는 선택한 열람실의 일간 그래프와 주간 혼잡도 표를 연결한다.
- `app/static/js/mock-history.mjs`는 가상 관측과 일간 및 주간 집계를 생성한다.
- `app/static/data/readingroom-layouts.json`은 `studyroom-manager` PoC의 배치도 사본이다. 이 작업은 학교 원문과의 현재 일치를 재검증하지 않았다.
- `app/main.py`는 web router와 `/studyroom/static`을 연결한다.

## 기능

열람실 카드는 가상 사용률과 빈 좌석 수를 표시한다. 사용자가 카드를 선택하면 해당 배치도가 표시된다. 좌석 번호 검색, 빈 좌석 강조와 좌석 선택을 지원한다. C1의 41번부터 44번은 위치 미확인 영역에 표시한다. 운영 중지 공간은 사용률 대신 이용 불가를 표시하고 좌석 상태는 미확인으로 제공한다.

좌석 상세는 상태, 좌석 이름, 예시 기준 시각과 사용 중 좌석의 잔여 및 종료 예정 시간을 표시한다. 만료 목록은 잔여 0분부터 30분까지의 사용 중 좌석을 빠른 순서로 표시한다. 잔여 시간이 없는 좌석은 목록에서 제외한다. 0분은 사용 중 상태를 유지하며 실제 빈자리 발생을 보장하지 않는다.

스터디룸은 여섯 방의 가상 현재 상태와 오늘부터 10일간의 예시 시간표를 표시한다. 날짜 선택은 시간표에만 적용한다. 사용자는 칸을 선택해 예약 범위를 확인한다. 시간표는 시작 :30, 종료 :20의 slot 표기 방식을 사용한다. 기록 없음은 예약 가능 확정을 뜻하지 않는다.

열람실 추이는 카드 선택에 따라 바뀐다. 일간 그래프는 24시간의 평균 사용률, 하루 평균과 최고 및 최저 구간을 표시한다. 주간 표는 기준 날짜가 속한 월요일부터 일요일까지의 2시간 구간을 표시한다. 사용자는 날짜와 주를 이동하거나 그래프의 점과 표의 칸을 선택해 사용률과 예시 표본 수를 확인한다.

혼잡도는 최근 90일 범위에서 가상 분 단위 관측으로 생성한다. 집계는 반올림 전 관측값을 합산하고 마지막에 반올림한다. 오늘은 가상 현재 14:10까지만 생성하며 미래, 휴실, 미수집과 보관 범위 밖을 구분한다. D1은 혼잡도 기록 대상이 아니므로 기록 대상 아님을 표시한다. 그래프와 표는 실제 DB 기록을 조회하지 않는다.

서버 상태 버튼은 실제 `/studyroom/health`를 호출하고 프로세스 생존만 확인한다. JS는 HTTP 오류, 응답 형식 오류, 연결 실패와 5초 timeout을 표시하고 재시도를 허용한다. 좁은 화면에서 배치도와 시간표는 내부 영역으로 스크롤한다.
